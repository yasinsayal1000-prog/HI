## 🔑 How to Get Telegram API ID & API Hash

Telegram API credentials can be created through Telegram's official developer portal.

1. Visit https://my.telegram.org
2. Sign in with your Telegram account.
3. Open **API Development Tools**.
4. Create an application if required.
5. Obtain your **api_id** and **api_hash**.
6. Enter the required credentials into the application.

Never publish your Telegram API credentials in a public GitHub repository. Keep your `api_id` and `api_hash` private.
